# Airbnb Price Prediction and Statistical Analysis

## Project Overview
This project analyses Airbnb listing prices in Paris using exploratory data analysis, statistical hypothesis testing, feature engineering, and machine learning regression models.

## Dataset
The analysis uses 91,031 Airbnb listings in Paris from Inside Airbnb data.

## Objectives
- Explore listing characteristics and price distributions.
- Investigate price differences across listing categories and other groups.
- Identify useful features for price prediction.
- Compare machine learning regression models.
- Evaluate model performance using appropriate regression metrics.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- XGBoost and LightGBM
- SciPy and Statsmodels
- Google Colab and Jupyter Notebook

## Methodology
- Data cleaning and preprocessing
- Exploratory data analysis
- Feature engineering and feature selection
- Statistical hypothesis testing, including ANOVA and the Kruskal–Wallis test
- Regression modelling and model comparison

## Results
LightGBM achieved an R² of approximately 0.70 in the reported model evaluation.

ANOVA and the Kruskal–Wallis test were also used to investigate statistical differences among groups in the analysis. These tests address group differences, not whether one prediction model is statistically superior to another.
